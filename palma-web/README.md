# PALMA VISION Web

نسخة ويب مبنية من APK الذي قدمه المالك: `PALMA-VISION-1.1.7-NO-ADS-DOWNLOAD-FIX.apk`.
بصمة المرجع: `e433d9e12233d7412cb624821ec29cc011b30a0bfb07eb84d18292db75eaabe1`.

الألوان والشعار وخط Cairo وخيارات المظهر مستخرجة من النسخة المقدمة. الواجهة العربية تعمل على الهاتف والكمبيوتر. مصدر Anime Witcher هو نفس البوابة التي يستعملها APK، والمصدر الرئيسي يستخدم عميلًا مستقلًا ينفّذ طلبات بالما وتوقيعها خارج Android. لا يحتاج إلى APK أو محاكي وقت التشغيل.

## التشغيل

Node.js 24، دون اعتماديات تشغيل npm:

```bash
cd palma-web
npm test
npm run dev
```

Vercel: اربط `awoadak-glitch/history`، وحدد Root Directory = `palma-web`، ثم `npm run build` وOutput Directory = `dist`.

## إعداد المصادر

- `PALMA_API_BASE`: رابط خادم المحتوى الرئيسي؛ الافتراضي الحالي تحقق حيًا بعد قراءة Remote Config.
- `PALMA_CERT_SHA256`: تعديل اختياري لبصمة شهادة APK العامة. لا يُستخدم مفتاح توقيع APK خاص.
- `PALMA_IMAGE_BASE`: تعديل اختياري لخادم الصور المرفوعة؛ افتراضيًا يتبع خادم API مثل التطبيق الأصلي. صور TMDB تستخدم مسارها الأصلي.
- `PALMA_APP_VERSION`: قيمة `app_version` الرقمية؛ الافتراضي `17` كما في Manifest النسخة المقدمة.
- `ANIME_API_BASE`: بوابة Anime Witcher المستعملة في النسخة الأصلية.
- `DRAMA_API_BASE` و`DRAMA_API_SUFFIX`: إعدادات عالم الدراما، محفوظة في متغيرات Vercel السرية؛ اللاحقة ليست منشورة في هذه النسخة من الويب.
- `MEDIA_TICKET_SECRET`: مفتاح عشوائي بطول 32 بايت أو أكثر لتوقيع روابط بروكسي الفيديو. اختياري؛ عند غيابه يولّد البناء مفتاحًا خاصًا لهذا النشر ويضمّنه فقط مع Functions. يستخدمه بروكسي المصادر التي تحتاج ترويسات أو إعادة كتابة HLS. لا يحتاج تشغيل Anime Witcher المباشر إلى هذا المفتاح. لا يستخدم العميل المفتاح ولا يستقبل Cookie أو رموز وصول الخادم.

المشروع لا يجري فحوص تحديث أو يضيف إعلانات. المفضلة والسجل ووقت الفيديو محفوظة في المتصفح، بمفاتيح مصدر/عمل/حلقة مستقرة بدل رابط الفيديو المتغير. تشغيل HTML5/HLS واختيار الجودة والسرعة والتنزيل يحتاجان رابط فيديو يمكن لخادم المصدر إتاحته للويب. روابط TDM الخاصة التي لا تحتوي HTTP media تعرض سبب التعذر.

## حدود التحقق الحالية

في 2026-10-14 نجح جلب الرئيسية الأصلية: 32 بانرًا و28 قسمًا، ثم التصنيفات وتفاصيل مسلسل وموسمه وحلقاته، وروابط CDN الموقعة من تفاصيل الحلقة والفيلم. جرى التحقق من قوائم HLS وأول جزء فيديو فعليًا. تقرير النشر والتشغيل: `docs/verification.md`.

الواجهة تستخدم ترتيب الأقسام وأنواعها الأصلية: العروض المميزة، المباريات، أحدث الحلقات، والبانرات التي تفتح التصنيفات. مصدر الأنمي في عالم المصادر يبقى AWR كما طلب المالك. مزامنة الحساب والتعليقات وإرسال الطلبات ليست ضمن مسار المحتوى المثبت. لا يصح الادعاء بأن كل سيرفر خارجي يعمل دون فحصه.

## MX Player و AWR MX

الإعداد الافتراضي هو مشغّل بالما المدمج HTML5/HLS على جميع الأجهزة. MX Player وAWR MX V7 خياران إضافيان في الإعدادات. بعد تجهيز السيرفر تظهر وصلة حقيقية لفتح التطبيق؛ يلزم ضغط المستخدم إذا انتهت مهلة تفعيل المتصفح أثناء جلب الرابط. MX يستخدم Android Intent مع مسار المتجر عند غياب التطبيق. AWR يستخدم `awrmx://play?data=<base64url JSON>`؛ حقول النسخة الأولى هي v/source/title/historyId وReferer/User-Agent الاختياريان.

مصدر مشغّل الكمبيوتر موجود في `../awr-mx-desktop`. التسجيل يكون للمستخدم الحالي عند فتح EXE، ولا يتيح الموقع الوصول إلى API التحكم المحلي أو سجل الكمبيوتر. الحفظ داخل المشغّل مستقل عن سجل المتصفح.

تنزيل الحزمة المرفقة بمحرك mpv متاح من صفحة `#/player-setup`. يثبّت `desktop-release.json` إصدار Windows الذي اجتاز CI؛ يجلبه أمر البناء من GitHub Release ويتحقق من SHA-256 وحجم الملف قبل نشره كتنزيل ثابت من نطاق بالما. حدّث البيان فقط بعد نجاح بناء Windows ونشر الإصدار الجديد.
