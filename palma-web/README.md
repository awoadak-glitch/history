# PALMA VISION Web

نسخة ويب مبنية من APK الذي قدمه المالك: `PALMA-VISION-1.1.7-NO-ADS-DOWNLOAD-FIX.apk`.
بصمة المرجع: `e433d9e12233d7412cb624821ec29cc011b30a0bfb07eb84d18292db75eaabe1`.

الألوان والشعار وخط Cairo وخيارات المظهر مستخرجة من النسخة المقدمة. الواجهة العربية تعمل على الهاتف والكمبيوتر. مصدر Anime Witcher هو نفس البوابة التي يستعملها APK، والمصدر الرئيسي يستخدم عقود Retrofit المستخرجة دون محاكاة توقيع Android.

## التشغيل

Node.js 22 أو أحدث، دون اعتماديات تشغيل npm:

```bash
cd palma-web
npm test
npm run dev
```

Vercel: اربط `awoadak-glitch/history`، وحدد Root Directory = `palma-web`، ثم `npm run build` وOutput Directory = `dist`.

## إعداد المصادر

- `PALMA_API_BASE`: رابط خادم المحتوى الرئيسي. الافتراضي هو العنوان الموجود في APK.
- `PALMA_API_TOKEN`: رمز وصول ويب يقدمه مالك الخادم، إن كان خادم الويب يستخدم Bearer authentication. لا ينسخ هذا المتغير توقيع Android.
- `PALMA_APP_VERSION`: قيمة `app_version` الرقمية؛ الافتراضي `17` كما في Manifest النسخة المقدمة.
- `ANIME_API_BASE`: بوابة Anime Witcher المستعملة في النسخة الأصلية.
- `DRAMA_API_BASE` و`DRAMA_API_SUFFIX`: إعدادات عالم الدراما، محفوظة في متغيرات Vercel السرية؛ اللاحقة ليست منشورة في هذه النسخة من الويب.
- `MEDIA_TICKET_SECRET`: مفتاح عشوائي بطول 32 بايت أو أكثر لتوقيع روابط بروكسي الفيديو. يجب ضبطه في Vercel. لا يستخدم العميل المفتاح ولا يستقبل Cookie أو رموز وصول الخادم.

المشروع لا يجري فحوص تحديث أو يضيف إعلانات. المفضلة والسجل ووقت الفيديو محفوظة في المتصفح، بمفاتيح مصدر/عمل/حلقة مستقرة بدل رابط الفيديو المتغير. تشغيل HTML5/HLS واختيار الجودة والسرعة والتنزيل يحتاجان رابط فيديو يمكن لخادم المصدر إتاحته للويب. روابط TDM الخاصة التي لا تحتوي HTTP media تعرض سبب التعذر.

## حدود التحقق الحالية

أثناء الفحص الأولي، بوابة Anime Witcher أعادت الرئيسية والبحث والتفاصيل و220 حلقة لناروتو وسيرفرات 1080p/720p/480p، وحل PD إلى رابط مباشر. خادم الأقسام الرئيسية أعاد `403` مع صفحة Cloudflare من بيئة الفحص. لم يتم تجاوز الحماية أو صنع محتوى بديل. تحدَّث نتائج اختبار Vercel في `docs/verification.md` بعد النشر.

مطابقة كل صفحات التطبيق ومحتواه ليست مثبتة: خادم المحتوى الرئيسي يجب أن يسمح باتصال الويب، ومزامنة حساب Android وتعليقاته والتوقعات لا تتوفر بهذه النسخة. انظر `docs/parity.md` للتفريق بين واجهة مجهزة، وربط مستخرج، وسلوك تحقق حيًا.
