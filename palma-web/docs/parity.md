# مقارنة APK مع الويب

هذه مقارنة هندسية، وليست شهادة مطابقة كاملة.

| المسار | التنفيذ في الويب | حد التحقق |
|---|---|---|
| الهوية والشعار والخط | أصول النسخة نفسها، Cairo، الألوان الذهبية والزرقاء | قراءة موارد APK؛ لم يُشغّل APK على محاكي |
| خيارات المظهر | الأصلية، البيضاء، مظلم بالما | تحتاج فحص تفاعلي في المتصفح |
| الرئيسية والأفلام والمسلسلات والأنمي الرئيسي والقنوات | نفس GET contracts في `server/contracts.json` | المصدر الرئيسي رفض طلب الويب بـ403 أثناء الفحص |
| المواسم والحلقات والسيرفرات الرئيسية | صفحات وربط لمسارات APK | الاختبار الحي مرتبط بقبول خادم المصدر |
| عالم المصادر: أنمي ويتشر | الرئيسية والبحث والفهارس والتفاصيل والحلقات والسيرفرات | مصدر حي أعاد 200 أثناء الفحص |
| عالم الدراما: المسلسلات والأفلام والقنوات | نفس المسارات، مع إعداد اللاحقة في الخادم | يحتاج فحص حي لكل قسم |
| المباريات والمصارعة والممثلون وسلاسل الأفلام | قوائم وتفاصيل أساسية | المصادر الرئيسية غير متاحة حاليًا؛ تبويبات الإحصاءات والبطولات الكاملة لم تُنقل |
| الملخصات والأهداف | قراءة قائمة الفيديوهات | تشغيل الفيديوهات غير منقول بعد |
| المشاهدة والتنزيل | فيديو HTML5 وHLS، اختيار الجودة، رابط تنزيل | السيرفرات التي تعيد HTTP media فقط؛ روابط TDM المغلقة غير مدعومة |
| موضع الفيديو | حفظ دوري وعند pause/pagehide/visibilitychange، مفتاح عمل/حلقة ثابت | اختبار الاستمرارية مع إغلاق وفتح المشغّل مطلوب |
| المفضلة والسجل | تخزين محلي، تصدير واستيراد بيانات الويب | مستقلان عن بيانات APK |
| حساب Android والتعليقات والتوقعات | غير منقول | يحتاج توثيق ويب معتمد من خادم المالك |

الويب يعرض خطأ المصدر بوضوح؛ لا يستبدل كتالوج بالما الأساسي بكتالوج آخر دون توضيح مصدر القسم.
