# التحقق

## الاختبارات المحلية

- نجحت 7 اختبارات للحدود: المسارات المسموحة، منع localhost/metadata، تذاكر الفيديو، قوائم HLS ومفاتيح التشفير، الروابط الخاصة، اختلاف بنى API، وحفظ الوقت مع تغير الرابط وإعادة تهيئة التخزين.
- نجح بناء الملفات الثابتة وفحص صياغة وحدات JavaScript.
- `index.html` وCSS وJavaScript والشعار تعيد HTTP 200 من الخادم المحلي بعد إصلاح التحقق من مسار الملفات.
- API الرئيسية والبحث في Anime Witcher يعيدان HTTP 200 عبر `api/catalog`.
- المصدر الرئيسي يعيد HTTP 403، مع JSON عربي يوضح فشل الاتصال. لا يعتبر نجاح واجهة الموقع نجاحًا لمحتوى المصدر الرئيسي.
- حل مصدر Naruto/001/PD أعاد رابط Pixeldrain مباشرًا من بوابة الأصل. خطوة الاتصال بالملف من بيئة العمل توقفت عند DNS (`EAI_AGAIN`)، لذلك تشغيل الفيديو والتنزيل لا يوصفان بأنهما متحققان محليًا.

## Vercel

رُفع المشروع إلى `awoadak-glitch/history` داخل `palma-web` بالالتزام `37a14c0f85be1e0fb2c3f13784019bb0ed6fa7d5`. إنشاء مشروع Vercel مستقل باسم `palma-vision-web` على فريق المالك رُفض برد 403: الاتصال الحالي لا يملك صلاحية إنشاء مشروع. تم بعد ذلك رفع نشر مؤقت باستخدام Vercel CLI 63.1.2 دون حساب، مع مفتاح فيديو عشوائي وإعداد عالم الدراما ضمن بيئة التشغيل. محاولة فتحه في المتصفح أعادت صفحة تسجيل دخول Vercel؛ لم يمكن التحقق من الواجهة أو طلبات المحتوى المنشورة. تحتاج المعاينة إلى نقلها لحساب المالك قبل انتهاء صلاحيتها. رابط النقل الخاص لم يُحفظ في المستودع العام. لم يتم إضعاف حماية النشر أو بدء تسجيل دخول من المتصفح. هذه النسخة ليست مطابقة كاملة لجميع صفحات ومحتوى APK، كما هو موضح في `parity.md`.

وسيلة النشر المحلية ليست مسجّلة بحساب Vercel. يبقى النشر الدائم وربطه بحساب المالك غير منجز.
