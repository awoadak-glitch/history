# التحقق — web.4 / AWR MX V7

## ما تم التحقق منه محليًا

- نجح بناء الموقع و14 اختبارًا تشمل ترتيب قوائم APK، تجهيز الأنمي دون مفتاح بروكسي، روابط Android Intent، بروتوكول AWR، الحروف العربية، الروابط الموقعة، ومعرّف الحلقة عبر تغيير السيرفر.
- نجحت اختبارات Go مع فحص السباقات وبناء EXE Windows 64-bit.
- مدخل awrmx يقبل رابط فيديو ومعرّف حلقة فقط؛ يرفض الملفات المحلية، عناوين localhost، أوامر التشغيل وحقول JSON غير المعتمدة. واجهة الكمبيوتر المحلية تحتاج مفتاح جلسة لا يُرسل إلى الموقع.
- حزمة mpv الرسمية تحتوي أرشيف ZIP متداخلًا؛ فُكّت الطبقتان وتحققت SHA-256 المنشورة مع أصل الإصدار. كود التغليف يتضمن المحرك وDLLs والمصدر.
- نجح [اختبار Windows رقم 38309735713](https://github.com/awoadak-glitch/history/actions/runs/38309735713): اختبارات Go، بناء EXE، تسجيل بروتوكول awrmx للمستخدم الحالي، وفك فيديو Y4M مصطنع بمحرك mpv.
- نُشرت [حزمة V7](https://github.com/awoadak-glitch/history/releases/tag/awr-mx-v7) بحجم 42,580,890 بايت. SHA-256: `4568a92d9e2769c4166ee167d544b3b04c485eb967f0bddc6bf6bb7b958a1755`.
- بناء الويب يجلب هذه الحزمة ويتحقق من حجمها وبصمتها ثم يضعها ضمن الملفات الثابتة في `/downloads/`. يفشل البناء عند عدم التطابق، ولا تمر الحزمة عبر حدود استجابات Vercel Functions.

## تحقق الموقع السابق

نسخة web.2 نُشرت على https://palma-web-lac.vercel.app/ . فُحصت القوائم وعالم المصادر والبحث عن Naruto وتفاصيله وحلقاته الـ220 والسيرفرات. تجهيز PD أعاد 200 ورابط 1080p. تشغيل هذا الملف داخل المتصفح السحابي فشل، لذلك لا يُدّعى نجاح تشغيل جميع الملفات. web.3 تضيف التسليم إلى المشغّلات الخارجية؛ استقبال Android الفعلي يتطلب هاتفًا مثبتًا عليه MX Player.

في فحص web.3 المنشور ظهرت إعدادات MX/AWR وسيرفرات حلقة Naruto الأولى الستة عشر. اختيار AWR ثم مشاهدة PD انتقل إلى طلب البروتوكول الخارجي؛ منعت سياسة المتصفح السحابي هذا البروتوكول (يسمح بـHTTP/HTTPS فقط). لم يُحاول تجاوز ذلك، ولا يُعد هذا تشغيلًا مثبتًا على جهاز المستخدم. أُكمل فحص صفحة إعداد المشغّل عبر HTTPS، وتبقى اختبارات إنشاء الروابط واختبار Windows المنفصل دليلي التحقق البرمجي.

## العائق الباقي في المحتوى

مصدر بالما الرئيسي ostvapp.cam أعاد 403 من بيئة العمل ومن نشر المالك. أظهر فحص APK أن طلبات /api/ الأصلية تستخدم توقيع IronFingerprint، وأن التطبيق يدير النطاق الرئيسي عبر Remote Config. لا يتوفر اتصال ويب معتمد لذلك الخادم في المشروع. تغيير المشغّل لا يصلح رفض جلب القوائم. يلزم عنوان API للويب وصلاحية يقبلها خادم المحتوى، أو تعديل خلفية المالك للسماح بالموقع.

Drama World: القنوات والتصنيفات نجحت في الفحص المباشر السابق، بينما الرئيسية والأفلام والمسلسلات أعادت 403. إعداد المصدر مطلوب في Vercel؛ لا يصح الإعلان عن عمل كل مصادر عالم الدراما.

## حدود التحقق

اختبارات Windows الآلية لا تثبت تشغيل كل مصدر إنترنت أو تجربة الصوت والواجهة على جهاز المستخدم. روابط TDM التي لا تحتوي HTTP media نهائيًا لا تُدفع إلى mpv كأنها فيديو. لم تُختلق قوائم أو ملفات فيديو بديلة.
