# التحقق — web.2

## تم التحقق

- نجح البناء وفحص صياغة وحدات JavaScript، و11 اختباراً.
- اختبار انحدار يعيد نفس ظروف العطل: VERCEL=1 وغياب MEDIA_TICKET_SECRET؛ تجهيز مصدر الأنمي يعيد 200 ورابطاً مباشراً.
- اختبار حي لمعالج /api/resolve مع Naruto / 001 / PD أعاد 200 و1080p وdelivery=direct من المصدر المطلوب awr-stream-web.vercel.app. لا يعاد جلب الفيديو أو توقيع رابط محلي قبل عرضه.
- التنزيل يحافظ على رابط المصدر وتوقيعه كما أعاده؛ لا تلحق به معاملات بروكسي بالما.
- اختبار ترتيب تبويبات APK وتحديد التبويب الصحيح داخل عالم المصادر وصفحات التفاصيل والسيرفرات.
- الشعار وخط Cairo و17 أيقونة متجهة من APK؛ شريطا التنقل منفصلان والقائمة الجانبية قابلة للفتح على الهاتف والكمبيوتر.

## حالة المحتوى

- مصدر بالما الأصلي ostvapp.cam يعيد 403 من بيئة العمل، وكذلك في نسخة المالك المنشورة. وصول صفحة HTML للموقع لا يعني نجاح محتوى بالما.
- Drama World: أعادت قائمة القنوات وقائمة التصنيفات 200 في الفحص المباشر؛ الرئيسية وقوائم المسلسلات والأفلام أعادت 403. إعداد المصدر مطلوب على نشر المالك. لم يُعلن نجاح كل مصادر عالم الدراما.
- API أنمي ويتشر يعيد الرئيسية والبحث والتفاصيل والحلقات والسيرفرات. اختبار تشغيل الفيديو داخل المتصفح بعد النشر ما زال مطلوباً.
- التوقيعات الأصلية لـAndroid وCloudflare لا يجري تجاوزهما. يلزم خادم محتوى يدعم عملاء الويب لإنهاء محتوى بالما.
