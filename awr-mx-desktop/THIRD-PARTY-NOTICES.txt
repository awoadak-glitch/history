AWR MX Desktop uses mpv and its bundled dependencies without modification.

The Windows engine is extracted from this first-party mpv release asset:
https://github.com/mpv-player/mpv/releases/download/v0.41.0/mpv-v0.41.0-x86_64-w64-mingw32.zip
SHA-256: a49811c0752c108b8260636f9c6f6fcb97406641c98b30f1e7b500dfb20177de
The release asset contains a nested Windows build archive. Both layers are unpacked.
