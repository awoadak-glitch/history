# PALMA VISION — Windows 2.2

نسخة مستقلة تجلب محتوى بالما مباشرة، من دون APK أو محاكي أو تثبيت Node.js.
فك ضغط الحزمة كاملة، ثم افتح `PALMA VISION.exe`. احتفظ ببقية الملفات بجانبه.

تستخدم النسخة نفس القوائم والواجهات العربية وعميل المصادر الموجود في `palma-web`.
المشغّل المدمج يتعرف على HLS وDASH وMPEG-TS وFLV وملفات الفيديو المباشرة،
حتى عندما يستخدم المصدر امتدادًا مختلفًا. يتضمن ملء شاشة حقيقي، اختيار السيرفر
والجودة والصوت والترجمة المتاحة، والسرعة من 0.5 إلى 4 واستكمال المشاهدة.
المسافة للتشغيل والإيقاف؛ الضغط المطوّل يرفع السرعة إلى 2× حتى ترك المفتاح.
F يبدّل ملء الشاشة، والأسهم للتقديم والصوت. يختفي شريط التحكم أثناء المشاهدة.
تفتح بطاقات المباريات صفحة الفرق والقنوات الفعلية وفيديوهات الأهداف والملخصات.
تعرض تفاصيل العمل الصور والتقييمات والممثلين وصنّاع العمل بحسب ما يوفره المصدر؛
الضغط على صورة الممثل يفتح أفلامه ومسلسلاته.
المفضلة والسجل محفوظان في بيانات التطبيق على Windows حتى بعد إغلاقه.
عند التنزيل تظهر نافذة حفظ Windows. ينزّل بالما أجزاء HLS ويجمعها في MP4
باستخدام محرك FFmpeg المرفق، دون الحاجة إلى TDM. صفحة التنزيلات تعرض التقدّم
والإلغاء وإعادة المحاولة وفتح مجلد الملف. الملفات التي اكتملت تبقى على الجهاز.
يستكمل جزءًا منقطعًا إذا دعم المصدر Range؛ إعادة فتح التطبيق تتيح إعادة المحاولة
برابط جديد، ولا يُدّعى استكمال كل الأجزاء بعد إغلاق مفاجئ.

لا يتصل التطبيق بنشر Vercel للحصول على محتوى بالما. يحتاج اتصال إنترنت يسمح
بالوصول إلى خادم المصدر. مصادر عالم الدراما التي تتطلب إعدادًا منفصلًا لم تُفعّل.
مصدر الأنمي يبقى بوابة AWR التي حددها المالك. لا توجد ضمانات لكل سيرفر خارجي.

هذا إصدار مختلف عن مشغّل المحاكي القديم الموجود في `palma-desktop`.
الحزمة غير موقعة بشهادة ناشر Windows؛ بصمتها ونتائج التحقق منشورتان مع الإصدار.

للمطور: `npm ci` ثم `npm start`. البناء: `npm run build:win`.
تُنقل ملفات العميل المشترك إلى الحزمة أثناء البناء؛ لا تُنسخ أي ملفات أسرار
أو لقطات استجابة أو APK. الواجهة معزولة دون Node أو صلاحيات ملفات.

محرك FFmpeg ملف تنفيذي منفصل، موزع من ffmpeg-static 5.3.0، ويحتفظ بملفات
README والترخيص الأصلية داخل `resources/ffmpeg`. المصدر وتعليمات البناء:
https://github.com/eugeneware/ffmpeg-static/releases/tag/b6.1.1
https://ffmpeg.org/download.html
لا تُنزّل أنواع الحماية غير المدعومة، ولا يُسجل البث المباشر بهذه الوظيفة.
