# PALMA VISION Windows 2.2.1 — نسخة تجريبية

فك ضغط ZIP بالكامل ثم افتح `PALMA VISION.exe`.

تتضمن مشغّلًا بواجهة جديدة، ملء الشاشة، تغيير السرعة والجودة والسيرفر،
وإصلاح روابط المباريات، وصور الممثلين وصفحات أفلامهم ومسلسلاتهم، وصور وتفاصيل الأعمال.
أضيفت محركات HLS وDASH وMPEG-TS وFLV وفحص نوع الفيديو من بياناته.

هذه نسخة للمراجعة وليست إصدارًا نهائيًا مثبتًا لكل المصادر.
اختبارات الواجهات والممثلين والمباريات نجحت. التحقق الحي من التشغيل مستمر؛
بعض مصادر بالما والقنوات ترفض التشغيل دون بيانات جلسة المصدر.
تأكد تشغيل حلقة Naruto 001 من أنمي ويتشر عبر PD بدقة 1440×1080 ومدة 23 دقيقة.
هذا التحديث يصحح الدخول والخروج من ملء الشاشة عبر نافذة Windows مباشرة.

لم تُضمّن بيانات جلسات المصدر أو الروابط الموقعة في المستودع أو حزمة البرنامج.
النسخة المستقرة السابقة 2.1 تبقى متاحة في إصدارها دون استبدال.
