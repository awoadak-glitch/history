# ربط المحتوى

المسارات مستخرجة من واجهة Retrofit الأصلية في عالم الدراما. لاحقة المسار الموجودة داخل APK يستخرجها build.py أثناء البناء من نسخة V4.2f المطابقة للبصمة. لا توجد جلسات حساب أو مفاتيح توقيع في ملفات المصدر المنشورة.

أضف `--drama inputs/drama.apk` لأمر البناء. عنوان الخدمة الافتراضي `https://dwapp.arabypros.com/api/` هو العنوان المعروف من التحليل؛ يمكن ضبطه عند البناء عبر `--api-base`. تحديث إعدادات الخدمة المحمية تلقائياً لم يُنقل بعد، ولا يتم إجراء طلب التحقق الذي رُفض سابقاً.

| الشاشة | المسار قبل اللاحقة |
|---|---|
| الرئيسية | first/ |
| المسلسلات | serie/by/filtres/{genre}/{order}/{page}/ |
| الأفلام | movie/by/filtres/{genre}/{order}/{page}/ |
| القنوات | channel/by/filtres/{category}/{country}/{page}/ |
| البحث | search/{query}/{page}/ |
| تفاصيل فيلم/مسلسل | movie/by/{id}/ |
| تفاصيل قناة | channel/by/{id}/ |
| المواسم والحلقات | season/by/serie/{id}/ |
| سيرفرات فيلم | movie/source/by/{id}/ |
| سيرفرات حلقة | episode/source/by/{id}/ |

الصفحات تبدأ من 0. الترتيب الافتراضي created، والخيارات الأصلية rating/imdb/title/year/views. البحث يرجع Data وفيه posters/channels، مع الحفاظ على هوية كل نتيجة. تمييز سيرفرات العرض والتنزيل يكون بالـ kind مع إبقاء ترتيب الرد.

الفحوص السابقة: بعض طلبات القنوات والتصنيفات رجعت 200؛ طلبات أخرى رفضتها Cloudflare بـ403 من بيئة العمل. لا يمكن اعتبار جميع مصادر المحتوى عاملة دون اختبار فعلي.
