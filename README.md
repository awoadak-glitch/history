# Oscar Pro + AWR Source World

تطوير داخل APK الأصلي، محفوظ بخطوات صغيرة. ابدأ بقراءة [RESUME.md](RESUME.md).

المسار المعتمد حاليًا: أوسكار Pro هو المضيف، و«عالم المصادر» واجهات وDEX مباشرة داخل التطبيق نفسه. لا توجد وحدة APK إضافية ولا محمّل DEX وقت التشغيل، و`assets/base.apk` الأصلي محفوظ بايتًا ببايت.

التبويبات: التبويبات الرئيسية، المسلسلات، الأفلام، القنوات. المشغل: `com.mxtech.videoplayer.ad`. تفاصيل البناء والتحقق في [docs/OSCAR-DIRECT-AWR.md](docs/OSCAR-DIRECT-AWR.md).

الحالة الحالية: APK موقع اجتاز التحقق البنيوي والتوقيع والمحاذاة؛ لم يُختبر على هاتف/محاكي ضمن بيئة البناء.
