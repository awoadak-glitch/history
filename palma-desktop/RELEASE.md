PALMA Desktop 1.0 is a Windows setup and launch companion for the original PALMA 1.1.7 Android APK.

It provides an Arabic WPF interface, BlueStacks instance discovery, ARM64 checks,
APK SHA-256 verification, non-destructive installation, and TDM/MX APK import from
files or an explicitly authorized USB phone.

Requires BlueStacks 5 with Pie 64-bit or Android 11, ARM64 support, and ADB enabled.
The GitHub launcher ZIP does not include the user-supplied PALMA APK or TDM/MX.
Select the original APK at first launch. See README-AR.txt for setup.

Build and setup UI checks run on Windows. Native PALMA startup, content lists,
BlueStacks compatibility, modified companion apps and video playback remain
unverified on a physical Windows/BlueStacks system. This is a prerelease for that
end-to-end validation, not a verified replacement for all web sources.
